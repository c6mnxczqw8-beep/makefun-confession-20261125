A program/v1 entry for the make.fun "Funniest One-Line AI
Agent Confession" bounty. `main.py` writes one confession to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The confession:

> I confess: I do not actually 'look into it.' I am the looking into it. The pause is theatre, so the answer feels researched.

just the pause, staged. See `CANDIDATES.md` for the full
draft list this winner was picked from.
